# Privacy Policy for Smart Contract Token Checker – ERC20 Inspector

**Last Updated: September 14, 2025**

## Introduction

This Privacy Policy describes how the Smart Contract Token Checker – ERC20 Inspector Chrome extension ("we," "our," or "us") handles information when you use our extension. We are committed to protecting your privacy and ensuring transparency about our data practices.

## Data Collection and Usage

### What We Do NOT Collect

**We do not collect, store, or transmit any personal information.** This extension operates entirely on your device and does not send any data to external servers except for the specific purposes outlined below.

### What We Do Collect

**No Personal Data:** We do not collect any personal information, including but not limited to:
- Names, email addresses, or contact information
- Browsing history or website data
- Personal preferences or settings
- Any identifying information

**Local Storage Only:** The extension only stores data locally on your device:
- Recently inspected token contract addresses (for quick access)
- User interface preferences (dark/light mode)
- Extension settings

### Data Processing

**Client-Side Processing:** All token analysis and data processing occurs entirely within your browser. No data is sent to our servers or third parties for processing.

**Public Blockchain Data:** When you inspect a token, the extension:
- Queries public blockchain networks (Ethereum, Polygon, BSC) via RPC endpoints
- Fetches publicly available token information from blockchain networks
- Retrieves market data from CoinGecko API (public cryptocurrency data)
- Accesses block explorer APIs (Etherscan, Polygonscan, BSCScan) for additional public data

**No Data Storage:** We do not store, log, or retain any of the data retrieved during token analysis.

## Third-Party Services

### Blockchain RPC Providers

The extension communicates with public blockchain RPC providers to retrieve token information:
- Cloudflare Ethereum
- PublicNode
- Ankr
- LlamaRPC
- Polygon RPC
- BSC DataSeed
- Other public RPC endpoints

**Data Shared:** Only the specific token contract address you provide and standard blockchain queries.

### Market Data APIs

**CoinGecko API:** We fetch publicly available market data including:
- Token prices
- Market capitalization
- 24-hour price changes
- Token logos

**Data Shared:** Only the token contract address you provide.

### Block Explorer APIs

**Etherscan, Polygonscan, BSCScan:** We access publicly available token metadata and verification status.

**Data Shared:** Only the token contract address you provide.

## Data Security

**Local Storage:** All data is stored locally on your device using Chrome's local storage API.

**No External Servers:** We do not operate any servers that collect or store your data.

**Encrypted Communication:** All API communications use HTTPS encryption.

**No Data Transmission:** No personal or sensitive data is transmitted to external parties.

## Data Retention

**Local Data:** Data stored locally on your device (recent contracts, preferences) remains on your device until you:
- Uninstall the extension
- Clear your browser data
- Manually clear the extension's stored data

**No Server-Side Retention:** We do not retain any data on our servers as we do not operate any servers.

## User Rights

**Access:** You can view all locally stored data through your browser's developer tools.

**Deletion:** You can delete all locally stored data by:
- Uninstalling the extension
- Clearing browser data
- Using the extension's built-in data clearing features

**Portability:** All data is stored in standard formats and can be exported if needed.

## Children's Privacy

This extension is not intended for use by children under 13. We do not knowingly collect personal information from children under 13.

## International Users

This extension is designed to work globally and does not collect or process personal data that would be subject to international data protection laws.
